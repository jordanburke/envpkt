## Global Install

```bash
npm install -g envpkt
# or
pnpm add -g envpkt
```

Once installed globally, the `envpkt` command is available everywhere:

```bash
envpkt --version
envpkt --help
```

## Local Install

Add envpkt as a dev dependency to your project:

```bash
npm install -D envpkt
# or
pnpm add -D envpkt
```

Then run via npx or package scripts:

```bash
npx envpkt audit
```

## Run Without Installing

```bash
npx envpkt env scan
npx envpkt audit
```

## Requirements

envpkt needs Node 22.12 or later, and nothing else. It seals, unseals and makes keys in-process
with [age-encryption](https://github.com/FiloSottile/typage), so you don't install the
[`age`](https://github.com/FiloSottile/age) CLI. The format is standard age: `age -d` decrypts what
envpkt seals, and envpkt unseals values sealed by `age`.

envpkt reads plain age key files, like the ones `envpkt keygen` and `age-keygen` write. A
passphrase-protected key file, an age plugin key or an SSH key fails with an error that names the
file. Run `envpkt doctor` to check that a config resolves and its key works.

## Library Usage

envpkt is also a TypeScript library. Import functions directly:

```typescript
import { boot, loadConfig, computeAudit, scanFleet } from "envpkt"
```

See the [Library API reference](/reference/library-api/) for full documentation.
